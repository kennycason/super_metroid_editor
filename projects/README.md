# Demo Projects

Each project lives in its own folder so ROMs, exports, assets, and save states stay grouped.

Included projects:

- `Super Mazetroid/Super Mazetroid.smedit`
- `Super Metroid Spike Olympics I/Super Metroid Spike Olympics I.smedit`

`Super Metroid Spike Olympics I/Super Metroid Spike Olympics I.smedit` is the main SMEDIT demo/reference project.

ROM files are intentionally ignored by git. To open the demo project locally, copy a legally obtained Super Metroid ROM to:

```text
projects/Super Metroid Spike Olympics I/Super Metroid Spike Olympics I.smc
```

The project files are configured to use repo-local ROM paths within their own project folders. Keep generated ROM exports and personal emulator state outside source control unless they are intentionally part of a demo bundle.
