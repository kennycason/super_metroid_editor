# Demo Projects

`Super Metroid Spike Olympics I.smedit` is the main SMEDIT demo/reference project.

ROM files are intentionally ignored by git. To open the demo project locally, copy a legally obtained Super Metroid ROM to:

```text
projects/Super Metroid Spike Olympics I.smc
```

The project file is configured to use that repo-local path. Keep generated ROM exports and personal emulator state outside source control.
